Two's complement (negative numbers)

Computers store signed whole numbers in two's complement. The left bit has a negative weight, so 1111 1111 in 8 bits is −1.

How to work it out by hand
  1. Write the positive number in binary using all the bits, e.g. 5 = 0000 0101.
  2. Flip every bit: 1111 1010.
  3. Add 1: 1111 1011. That's −5.

To read one back, if the left bit is 1, the value is the unsigned number minus 2bits. For example, 1111 1011 = 251 − 256 = −5.
